# Repository Analysis

Use before non-trivial implementation.

1. Identify solution/project structure.
2. Identify entry points.
3. Find related controllers/services/repositories/components.
4. Find existing patterns similar to the requested change.
5. Identify test coverage.
6. Identify DB/API/config impacts.
7. Produce a concise implementation plan.

Do not modify code during analysis unless explicitly asked.
