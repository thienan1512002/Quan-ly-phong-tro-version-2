# Code Review

Review:
1. Requirement coverage
2. Business-rule correctness
3. Architecture consistency
4. Null/error handling
5. Data integrity
6. Concurrency
7. Security
8. Performance
9. Tests
10. Unrelated changes

Report findings by severity:
- BLOCKER
- HIGH
- MEDIUM
- LOW
