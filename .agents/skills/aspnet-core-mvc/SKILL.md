# ASP.NET Core MVC

- Follow existing routing and controller conventions.
- Prefer view models over exposing persistence entities directly.
- Preserve antiforgery/authentication/authorization behavior.
- Keep validation consistent between server and client where applicable.
- Do not move business rules into Razor views.
