# Security Review

Check:
- authentication/authorization
- input validation
- SQL injection
- command injection
- path traversal
- secret leakage
- insecure logging
- IDOR / object-level authorization
- unsafe deserialization
- overly broad permissions

Do not weaken security controls to satisfy a feature request.
